# SmartTube Moderne

SmartTube (https://github.com/yuliskov/SmartTube, licence MIT) avec un thème « Moderne » façon Netflix / Apple TV :

- fond sombre dégradé avec une lueur violet/corail
- barre latérale semi-transparente
- vignettes plus arrondies, plus espacées, qui grossissent davantage au focus
- titres en police medium, sous-titres adoucis
- couleur d'accent corail (#FF4D6A) sur la barre de lecture, la progression et les boutons
- appli séparée (`org.smarttube.moderne`) : elle s'installe à côté du SmartTube officiel, sans mise à jour auto qui l'écraserait

Le thème s'active tout seul. On peut revenir aux anciens : Réglages → Interface → Thème de couleur.

## Compiler
Onglet **Actions** → « Compiler SmartTube Moderne » → **Run workflow**. L'APK est dans **Artifacts** à la fin (~10 min).
Sur Chromecast avec Google TV, installer le fichier `_armeabi-v7a.apk`.
